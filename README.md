## Connect your Android device

1. Install the MirrorCat Android companion and the desktop app.
2. Connect using USB or the same local Wi-Fi network.
3. Follow the connection instructions in the app and select a mapping profile.

Android companion: 0.2.24 / versionCode 26. The Google Play closed-test update has been submitted and is awaiting processing/review.

This beta is still being tested. Controls and compatibility can vary between games. Commercial/codec redistribution review remains incomplete.
