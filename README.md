# MirrorCat

View your Android screen on your computer and customize keyboard and mouse mappings. You can also connect a keyboard and mouse directly to your Android device for standalone controls.

## Connect your Android device

1. Install the latest MirrorCat Android companion and desktop app together.
2. Connect using USB or the same local Wi-Fi network. Follow the in-app registration instructions for Wi-Fi control.
3. Select a mapping profile. Input-only connection is available without screen sharing.

Android companion: 0.2.136 (version code 138) has been submitted to Google Play closed Alpha. Version 0.2.124 (code 126) was available to testers at submission. Android files are distributed separately from this desktop release.

This is a test beta. Controls and compatibility can vary between games and devices. Windows is unsigned. Commercial/codec redistribution review remains incomplete.
